웹애플리케이션로그_1_CSV추출.py 실행 방법

[하는 일]
서버 로그(chatservice.log)에서 웹 애플리케이션 로그만 골라 CSV 파일로 옮긴다. SQL 기록(p6spy가 남긴 기록)은 넣지 않는다.
서버 로그에서 로그 한 건은 날짜와 시각으로 시작하는 줄에서 시작한다. SQL 기록은 SQL 문장 안의 줄바꿈 때문에 여러 줄로 이어지므로,
날짜·시각 줄을 만나면 새 로그로 보고 다음 날짜·시각 줄 전까지의 줄을 그 로그에 붙인 뒤, 로그를 남긴 클래스가 p6spy인 로그를 뺀다.
CSV에는 로그 한 건을 한 행으로 두고, 서버 시각·로그 레벨·서버 스레드·로그를 남긴 클래스·메시지를 열로 나눈다. 메시지는 글자를 바꾸지 않는다.
원본 로그는 바꾸지 않는다. 출력 파일이 이미 있으면 덮어쓰지 않고 중단한다.

[실행 명령] PowerShell에서 아래 두 명령을 차례로 실행한다.

cd "E:\devSpace\SpringBootProjects\ChatService\docs\5. 병목지점\작업산출물\작업\003_거래정합성_검증과_기술적의사결정\세부작업\04_테스트_기존거래가있는상품의_예약과등록가격구매_경합\실행결과_원본\실행01_가격제안수락1건과등록가격결제1건동시요청_20261113\웹서버로그파일"

py -V:3.13 .\웹애플리케이션로그_1_CSV추출.py --log .\chatservice.log --output "E:\devSpace\SpringBootProjects\ChatService\docs\5. 병목지점\작업산출물\작업\003_거래정합성_검증과_기술적의사결정\세부작업\04_테스트_기존거래가있는상품의_예약과등록가격구매_경합\실행결과_가공\실행01_가격제안수락1건과등록가격결제1건동시요청_20261113\실행01_웹애플리케이션로그_1_원본추출.csv"

[인자]
--log     원본 서버 로그 파일
--output  만들 CSV 파일. 폴더가 없으면 만든다

[py -V:3.13]
이 노트북에 설치된 Python 3.13으로 실행하라는 뜻이다. python 명령은 Python 설치 관리자로 연결되어 있어 쓰지 않는다.

[CSV의 열]
원본 줄 번호        서버 로그에서 이 로그가 시작되는 줄의 번호
원본 줄 수          이 로그가 서버 로그에서 차지한 줄 수. 메시지가 여러 줄이면 2 이상이다
서버 시각           서버가 로그 줄 맨 앞에 기록한 시각(한국 시각, 밀리초까지). 서버 로그의 글자 그대로다
로그 레벨           INFO, WARN, ERROR 등
프로세스 번호       서버 애플리케이션의 프로세스 번호
애플리케이션        로그를 남긴 애플리케이션 이름
서버 스레드         이 로그를 남긴 서버 스레드
로그를 남긴 클래스  이 로그를 남긴 코드의 클래스 이름. 패키지 이름은 서버 로그에서 앞 글자로 줄여 기록된다
메시지              로그 메시지 원문. 여러 줄이면 줄바꿈을 그대로 둔다

[결과 확인]
실행하면 화면에 원본 줄 수, 로그 건수와 뺀 SQL 기록 건수, CSV에 넣은 웹 애플리케이션 로그 건수, 첫 로그와 마지막 로그의 시각, 저장한 파일 경로가 나온다.
실행01의 서버 로그로 실행하면 원본 2542줄에서 로그 1346건이 나오고, SQL 기록 598건을 뺀 웹 애플리케이션 로그 748건이 CSV에 들어간다.
그 가운데 이번 테스트에서 추가한 로그(「| 실행ID=」가 들어 있는 로그)는 34건이다. 검증 요청 2건(accept-new, buy-new)의 로그 17건과, 같은 실행 ID로 남은 준비 요청 2건(기존 주문을 만든 준비 결제 prep-order-existing, 기존 예약을 만든 준비 수락 prep-accept-existing)의 로그 17건이다.
첫 로그 시각은 12:55:38.573, 마지막 로그 시각은 15:18:28.730이다. 15:01 전의 로그는 이번 테스트가 아닌 다른 사용자의 요청에서 남은 것이다.

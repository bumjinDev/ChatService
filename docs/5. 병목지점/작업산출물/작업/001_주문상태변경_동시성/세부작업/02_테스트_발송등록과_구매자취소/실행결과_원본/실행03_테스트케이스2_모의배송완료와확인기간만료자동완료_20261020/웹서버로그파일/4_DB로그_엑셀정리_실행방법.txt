4_DB로그_엑셀정리.py 실행 방법

[하는 일]
3번 스크립트로 뽑은 p6spy 기록(서버가 DB에 보낸 SQL과 커밋의 기록)을 엑셀 파일 하나로 정리한다.
p6spy 기록에는 서버 스레드 이름만 있고 어느 요청의 기록인지는 없으므로, 1번 스크립트로 뽑은 서버 로그(시각추출 파일)를 함께 읽어
각 서버 스레드가 그 시각에 어느 요청을 처리하고 있었는지 알아낸다. 시각추출 파일의 내용은 엑셀에 넣지 않는다.
입력 파일은 읽기만 한다. 출력 파일이 이미 있으면 덮어쓰지 않고 중단한다.
이 스크립트는 실행02의 스크립트를 실행03의 요청 구성(JMeter 요청 C-2~C-7, 그 가운데 C-3 모의 배송 완료와 C-5 확인 기간 만료 자동 완료는 테스트 지원 API)에 맞게 고친 사본이다.
테스트 지원 API의 요청은 서버 로그에 「요청 처리 시작」 기록이 없으므로, 요청이 끝날 때 남는 「[테스트 자동 처리 실행]」 기록으로 그 요청을 찾는다.
저장한 값 열에는 주문의 거래 상태·배송 상태·완료 사유·배송 완료 시각·상품 확인 기한·종료 시각과, 지갑과 잔액 변동 내역의 값을 넣는다.

[시트 구성]
1_원본       p6spy 기록 하나를 한 행으로 두고, 서버 시각·서버 스레드·커넥션 번호·기록 종류·p6spy가 기록한 실행 시간·SQL로 나눈다.
2_요청별정리 기록을 요청(C-2~C-7)별로 묶고, 요청 안에서는 트랜잭션별로 묶는다. SQL에서 SQL 종류·대상 테이블·WHERE 조건·저장한 값을 꺼내 열로 둔다.
3_시간값     두 자동 처리(C-3, C-5)의 SQL과 커밋을 한 표에 서버 시각순으로 둔다. 오른쪽에 서버 로그에 남은 두 자동 처리의 실행 기록(넘긴 now, 처리 건수)을 둔다.
각 시트 아래에는 열마다 무슨 데이터인지 적은 열 설명 표가 있다.

[실행 명령] PowerShell에서 아래 두 명령을 차례로 실행한다.

cd "E:\devSpace\SpringBootProjects\ChatService\docs\5. 병목지점\작업산출물\작업\001_주문상태변경_동시성\세부작업\02_테스트_발송등록과_구매자취소\실행결과_원본\실행03_테스트케이스2_모의배송완료와확인기간만료자동완료_20261020\웹서버로그파일"

py -V:3.13 .\4_DB로그_엑셀정리.py --p6spy "..\..\..\실행결과_가공\실행03_테스트케이스2_모의배송완료와확인기간만료자동완료_20261020\실행03_서버로그_p6spy추출.log" --log "..\..\..\실행결과_가공\실행03_테스트케이스2_모의배송완료와확인기간만료자동완료_20261020\실행03_서버로그_시각추출.log" --output "..\..\..\실행결과_가공\실행03_테스트케이스2_모의배송완료와확인기간만료자동완료_20261020\실행03_DB로그_정리.xlsx"

[인자]
--p6spy   3번 스크립트로 뽑은 p6spy 기록 파일
--log     같은 실행에서 1번 스크립트로 뽑은 서버 로그 파일(시각추출 파일). 요청을 알아내는 데만 쓴다
--output  만들 엑셀 파일. 폴더가 없으면 만든다

[py -V:3.13]
이 노트북에 설치된 Python 3.13으로 실행하라는 뜻이다. 엑셀 파일을 만드는 openpyxl이 이 Python에 설치되어 있다.

[결과 확인]
실행하면 화면에 p6spy 기록 수와 기록 종류별 수, 요청별 서버 스레드와 기록 수, 요청 안의 트랜잭션별 커넥션 번호·트랜잭션 성격·기록 수·커밋 시각,
저장한 파일 경로가 나온다.
실행03으로 실행하면 43건(SQL 실행 37건, 커밋 6건)이 나온다. C-3은 커넥션 10(대상 주문 조회, 커밋 기록 없음)과 11(데이터를 바꾼 트랜잭션, 03.754 커밋),
C-5는 커넥션 13(대상 주문 조회, 커밋 기록 없음)과 14(데이터를 바꾼 트랜잭션, 03.890 커밋)를 썼고, C-2·C-4·C-6·C-7은 커넥션 9·12·15·16에서 조회만 했다고 나온다.

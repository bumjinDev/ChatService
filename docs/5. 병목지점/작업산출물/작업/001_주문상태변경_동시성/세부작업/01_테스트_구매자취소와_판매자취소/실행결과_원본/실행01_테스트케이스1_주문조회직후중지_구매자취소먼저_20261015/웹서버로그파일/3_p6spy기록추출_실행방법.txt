3_p6spy기록추출.py 실행 방법

[하는 일]
서버 로그에서 p6spy 기록(서버가 DB에 보낸 SQL과 커밋의 기록)만 뽑아 새 파일로 저장한다.
p6spy 기록은 시각 줄 하나와 그 뒤의 SQL 두 줄(값 자리가 ?로 적힌 바인딩 전 SQL, ? 자리에 실제 값을 넣은 바인딩 후 SQL)로 이루어지며, 세 줄을 함께 뽑는다.
커밋 기록은 SQL 문장이 없어 시각 줄 뒤에 빈 줄과 ';' 줄이 이어지며, 이 줄들도 함께 뽑는다.
원본 로그는 바꾸지 않는다. 출력 파일이 이미 있으면 덮어쓰지 않고 중단한다.

[실행 명령] PowerShell에서 아래 두 명령을 차례로 실행한다.

cd "E:\devSpace\SpringBootProjects\ChatService\docs\5. 병목지점\작업산출물\작업\001_주문상태변경_동시성\세부작업\01_테스트_구매자취소와_판매자취소\실행결과_원본\실행01_테스트케이스1_주문조회직후중지_구매자취소먼저_20261015\웹서버로그파일"

py -V:3.13 .\3_p6spy기록추출.py --input "..\..\..\실행결과_가공\실행01_서버로그_시각추출.log" --output "..\..\..\실행결과_가공\실행01_서버로그_p6spy추출.log"

[인자]
--input   p6spy 기록을 뽑을 서버 로그 파일. 1번 스크립트로 시각 범위를 뽑은 파일을 넣는다
--output  뽑은 결과를 저장할 파일. 폴더가 없으면 만든다

[py -V:3.13]
이 노트북에 설치된 Python 3.13으로 실행하라는 뜻이다. python 명령은 Python 설치 관리자로 연결되어 있어 쓰지 않는다.

[결과 확인]
실행하면 화면에 원본 줄 수, 뽑은 p6spy 기록 수와 줄 수, 구분별 기록 수(statement는 SQL을 보낸 기록, commit은 커밋한 기록),
첫 기록과 마지막 기록의 시각, 저장한 파일 경로가 나온다.
실행01로 실행하면 38건, 114줄(statement 32건, commit 6건)이 나오고, 첫 기록 시각은 15:20:44.798, 마지막 기록 시각은 15:20:45.458이다.

4_DB로그_엑셀정리.py 실행 방법

[하는 일]
3번 스크립트로 뽑은 p6spy 기록(서버가 DB에 보낸 SQL과 커밋의 기록)을 엑셀 파일 하나로 정리한다.
p6spy 기록에는 서버 스레드 이름만 있고 어느 요청의 기록인지는 없으므로, 1번 스크립트로 뽑은 서버 로그(시각추출 파일)를 함께 읽어
각 서버 스레드가 그 시각에 어느 요청을 처리하고 있었는지 알아낸다. 시각추출 파일의 내용은 엑셀에 넣지 않는다.
입력 파일은 읽기만 한다. 출력 파일이 이미 있으면 덮어쓰지 않고 중단한다.

[시트 구성]
1_원본       p6spy 기록 하나를 한 행으로 두고, 서버 시각·서버 스레드·커넥션 번호·기록 종류·DB 실행 시간·SQL로 나눈다.
2_요청별정리 기록을 요청(요청 A, 요청 B, A-1, B-1)별로 묶고, 요청 안에서는 트랜잭션별로 묶는다. SQL에서 SQL 종류·대상 테이블·WHERE 조건·저장한 값을 꺼내 열로 둔다.
3_시간값     요청 A와 요청 B의 데이터를 바꾼 트랜잭션을 한 표에 서버 시각순으로 둔다. 오른쪽에 계산값 표(각 트랜잭션의 첫 SQL부터 커밋까지의 시간, 두 트랜잭션이 동시에 진행된 구간)를 둔다.
각 시트 아래에는 열마다 무슨 데이터인지 적은 열 설명 표가 있다.

[실행 명령] PowerShell에서 아래 두 명령을 차례로 실행한다.

cd "E:\devSpace\SpringBootProjects\ChatService\docs\5. 병목지점\작업산출물\작업\001_주문상태변경_동시성\세부작업\01_테스트_구매자취소와_판매자취소\실행결과_원본\실행01_테스트케이스1_주문조회직후중지_구매자취소먼저_20261015\웹서버로그파일"

py -V:3.13 .\4_DB로그_엑셀정리.py --p6spy "..\..\..\실행결과_가공\실행01_테스트케이스1_주문조회직후중지_구매자취소먼저_20261015\실행01_서버로그_p6spy추출.log" --log "..\..\..\실행결과_가공\실행01_테스트케이스1_주문조회직후중지_구매자취소먼저_20261015\실행01_서버로그_시각추출.log" --output "..\..\..\실행결과_가공\실행01_테스트케이스1_주문조회직후중지_구매자취소먼저_20261015\실행01_DB로그_정리.xlsx"

[인자]
--p6spy   3번 스크립트로 뽑은 p6spy 기록 파일
--log     같은 실행에서 1번 스크립트로 뽑은 서버 로그 파일(시각추출 파일). 요청을 알아내는 데만 쓴다
--output  만들 엑셀 파일. 폴더가 없으면 만든다

[py -V:3.13]
이 노트북에 설치된 Python 3.13으로 실행하라는 뜻이다. 엑셀 파일을 만드는 openpyxl이 이 Python에 설치되어 있다.

[결과 확인]
실행하면 화면에 p6spy 기록 수와 기록 종류별 수, 요청별 서버 스레드와 기록 수, 요청 안의 트랜잭션별 커넥션 번호·트랜잭션 성격·기록 수·커밋 시각,
저장한 파일 경로가 나온다.
실행01로 실행하면 38건(SQL 실행 32건, 커밋 6건)이 나오고, 요청 A는 커넥션 379(데이터를 바꾼 트랜잭션, 45.228 커밋)와 380,
요청 B는 커넥션 378(데이터를 바꾼 트랜잭션, 45.449 커밋)과 381을 썼다고 나온다.

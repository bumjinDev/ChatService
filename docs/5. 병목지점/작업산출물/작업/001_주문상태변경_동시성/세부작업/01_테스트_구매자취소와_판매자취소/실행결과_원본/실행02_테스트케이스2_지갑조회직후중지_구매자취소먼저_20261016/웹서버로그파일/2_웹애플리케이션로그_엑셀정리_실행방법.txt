2_웹애플리케이션로그_엑셀정리.py 실행 방법

[하는 일]
1번 스크립트로 뽑은 서버 로그에서 웹 애플리케이션 로그(p6spy 기록을 뺀 로그)를 엑셀 파일 하나로 정리한다.
p6spy 기록(SQL 실행 로그)은 DB 측 로그로 따로 정리하므로 이 파일에 넣지 않는다.
입력 파일은 읽기만 한다. 출력 파일이 이미 있으면 덮어쓰지 않고 중단한다.

[시트 구성]
1_원본       웹 애플리케이션 로그 기록 하나를 한 행으로 두고, 서버 시각·로그 레벨·서버 스레드·클래스·메시지로 나눈다.
2_요청별정리 기록을 요청(요청 A, 요청 B, A-1, B-1)별로 묶고, 메시지에서 주문 ID·취소 주체·금액·변동 후 잔액·중지 위치를 꺼내 열로 둔다.
3_시간값     요청 A와 요청 B의 주요 시점을 클라이언트 시각과 서버 시각으로 나누어 둔다. 오른쪽에 계산값 표(대기 시간, 두 시계의 차이, 응답을 받은 시각)를 둔다.
각 시트 아래에는 열마다 무슨 데이터인지 적은 열 설명 표가 있다.

[실행 명령] PowerShell에서 아래 두 명령을 차례로 실행한다.

cd "E:\devSpace\SpringBootProjects\ChatService\docs\5. 병목지점\작업산출물\작업\001_주문상태변경_동시성\세부작업\01_테스트_구매자취소와_판매자취소\실행결과_원본\실행02_테스트케이스2_지갑조회직후중지_구매자취소먼저_20261016\웹서버로그파일"

py -V:3.13 .\2_웹애플리케이션로그_엑셀정리.py --log "..\..\..\실행결과_가공\실행02_테스트케이스2_지갑조회직후중지_구매자취소먼저_20261016\실행02_서버로그_시각추출.log" --jtl ..\결과.jtl --resume ..\재개제어_기록.txt --output "..\..\..\실행결과_가공\실행02_테스트케이스2_지갑조회직후중지_구매자취소먼저_20261016\실행02_웹애플리케이션로그_정리.xlsx"

[인자]
--log     1번 스크립트로 뽑은 서버 로그 파일
--jtl     같은 실행의 JMeter 결과 파일(결과.jtl). 취소 요청을 보낸 시각과 응답까지 걸린 시간을 가져온다
--resume  같은 실행의 재개 제어 기록 파일(재개제어_기록.txt). 재개 제어가 기록한 시각을 가져온다
--output  만들 엑셀 파일. 폴더가 없으면 만든다

[py -V:3.13]
이 노트북에 설치된 Python 3.13으로 실행하라는 뜻이다. 엑셀 파일을 만드는 openpyxl이 이 Python에 설치되어 있다.

[결과 확인]
실행하면 화면에 웹 애플리케이션 로그 기록 수, 요청별 회원 ID·메서드와 경로·서버 스레드·기록 수, 저장한 파일 경로가 나온다.
실행02로 실행하면 기록 24건, 요청 A 8건, 요청 B 8건, A-1 4건, B-1 4건이 나온다.

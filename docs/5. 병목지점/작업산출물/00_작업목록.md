# 작업 목록

## 1. 프로젝트 개요

ChatService를 개인 간 중고거래 서비스로 확장한 C2C Marketplace를 대상으로 한다. 같은 주문이나 상품, 지갑을 여러 요청이 거의 동시에 바꿀 때 생길 수 있다고 코드를 읽고 추정한 정합성 문제가 실제로 생기는지, 실제 요청과 Oracle 데이터로 확인한다. 확인한 결과를 근거로 현재 설계를 유지할지 고칠지 정하고, 그 과정과 결과를 취업 포트폴리오의 사례로 정리한다.

- 대상: ChatService 저장소의 `develop` 브랜치. 실행되는 코드는 `com.chatservice.marketplace` 패키지다.
- 외부 경로는 저장소 루트(`E:\devSpace\SpringBootProjects\ChatService`) 기준이다.

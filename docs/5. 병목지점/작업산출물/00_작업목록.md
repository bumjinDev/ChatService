# 작업 목록

## 1. 프로젝트 개요

ChatService를 개인 간 중고거래 서비스로 확장한 C2C Marketplace 기본 구현에서, 비즈니스 시나리오 분석 보고서가 코드 근거로 추정한 정합성 문제를 실제 요청과 Oracle 데이터로 확인하는 프로젝트다. 확인 결과를 근거로 현재 설계를 유지할지 개선할지를 사용자가 정하고, 그 과정과 결과를 신입 백엔드 개발자 취업 포트폴리오의 사례 자료로 쓴다.

- 대상 시스템: ChatService 저장소 `develop` 브랜치(작업 시작 시 최신 커밋 `3244d84`), 실행 코드 패키지 `com.chatservice.marketplace`
- 외부 경로는 저장소 루트(`E:\devSpace\SpringBootProjects\ChatService`) 기준으로 적는다.

기준 자료는 다음과 같다.

| 자료 | 위치 | 이 프로젝트에서 쓰는 내용 |
|---|---|---|
| 요구사항 명세서 1.1 | 외부: `docs/4. 프로젝트고도화/2. C2C_Marketplace_요구사항_명세서.md` | 업무 규칙 BR-001~BR-008, 기능별 허용·거절 조건과 수용 기준 |
| 설계 명세서 2.1 | 외부: `docs/4. 프로젝트고도화/3. C2C_Marketplace_설계_명세서.md` | 상태 전환, 기능별 처리 순서, 자동 실행, 검증 계획 |

산출물 관리 기준은 외부: `E:\devSpace\문서 작성 양식\프로젝트_작업산출물_관리명세서.md`를 따른다. 이 명세서는 개인 작성 양식이라 저장소 안에 복사하지 않으며, 산출물 루트는 명세서 위치가 아니라 이 폴더(`docs/5. 병목지점/작업산출물/`)로 지정한다.

작업산출물 폴더는 커밋하고, 기타 폴더의 참고 자료는 커밋하지 않는다.
